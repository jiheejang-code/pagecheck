# PageCheck — 웹 접근성 검수 도구

웹페이지 주소를 넣으면 실제 Chrome/Edge로 접근성 문제를 찾아 주고, 수정 후 다시 검사해 해결 여부를 비교해 주는 도구입니다.

- 온라인 화면(예시 결과 보기): https://jiheejang-code.github.io/pagecheck/
- 실제 검사는 **각자 PC에서** 실행합니다. 검사한 회사 페이지와 결과는 내 PC 밖으로 나가지 않습니다.

## 처음 쓰는 팀원 — 3단계

1. **실행 패키지 받기**
   [pagecheck-local.zip 다운로드](https://jiheejang-code.github.io/pagecheck/pagecheck-local.zip) → 원하는 곳(예: 문서 폴더)에 **압축 풀기**
2. **`PageCheck열기.bat` 더블클릭**
   처음 한 번은 자동 설치에 1~2분 걸립니다. 잠시 후 브라우저에 PageCheck가 열립니다.
3. **검수 시작**
   화면 위쪽 **새 검수** → 검사할 주소 입력 → **빠른 점검**부터 해 보세요.

검은 실행 창은 쓰는 동안 열어 두세요. 창을 닫으면 PageCheck가 꺼집니다.
다음부터는 2번만 하면 됩니다. 바탕화면에 바로 가기를 만들어 두면 편합니다.

### 필요한 것

- Windows
- Chrome 또는 Edge
- Node.js 20 이상 — 없으면 실행할 때 설치 페이지가 열립니다. **LTS** 버전을 설치한 뒤 다시 더블클릭하세요.

### 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 브라우저가 열리지 않음 | 직접 http://127.0.0.1:47831 을 여세요. |
| “설치하지 못했습니다” | 인터넷(회사 프록시 포함) 연결을 확인하고 다시 실행하세요. |
| “Chrome 또는 Edge를 실행하지 못했습니다” | Chrome이나 Edge를 설치·업데이트하세요. |
| 새 버전으로 바꾸고 싶음 | 새 zip을 **같은 폴더에 덮어써서** 풀면 됩니다. 기존 검사 기록(data 폴더)은 그대로 남습니다. |

### 알아 두기

- 검수 기록은 **각자의 PC에만** 저장되고 팀원끼리 자동으로 공유되지 않습니다. 결과를 공유하려면 결과 화면에서 **JSON 내보내기** → 받은 사람이 **가져오기** 하세요.
- 로그인이 필요한 페이지는 새 검수의 **로그인 브라우저 열기**로 직접 로그인한 뒤 검사합니다. PageCheck에 비밀번호를 입력하지 마세요.
- 자동 검사로 모든 접근성 문제를 찾을 수는 없습니다. 키보드·스크린리더 실사용, 대체 텍스트의 적절성 등은 사람이 확인해야 합니다.
- **결과 보는 법:** ‘문제 목록’에서 문제를 고르면 위치(빨간 상자)와 무엇이 문제인지(예: 명도 대비 수치·색상)가 나옵니다. ‘자동 규칙·검사 기록’ 탭에서는 실행한 자동 규칙 전체의 결과(문제 발견·확인 필요·통과·검사할 요소 없음)를, ‘기준별 평가’ 탭에서는 사람이 확인해야 할 WCAG 기준을 봅니다.
- 내보낸 결과 파일이나 data 폴더를 이 공개 저장소에 올리지 마세요.

자세한 기능 설명은 압축을 푼 폴더의 `README-ko.md`에 있습니다.

## 관리자용 — 새 버전 올리기

1. 로컬 패키지 폴더에서 화면(`dist/`)이나 엔진을 고친 뒤, `dist/`의 파일을 이 저장소 최상위에 복사합니다.
2. 패키지 폴더를 다시 압축해 `pagecheck-local.zip`을 교체합니다. `node_modules`, `data`, `package-lock.json`은 넣지 않습니다.
3. 화면을 바꿨다면 `index.html`의 `app.js?v=` 숫자를 올려야 팀원 브라우저에 바로 반영됩니다.
4. main 브랜치에 올리면 1~2분 뒤 GitHub Pages에 반영됩니다(Settings → Pages: main, /(root)).

### 온라인 화면에 엔진 연결하기 (선택)

대부분은 `PageCheck열기.bat`로 여는 로컬 화면이면 충분합니다. 온라인 화면에서 직접 검사하려면 `온라인연결.bat`를 실행하고 `https://jiheejang-code.github.io/pagecheck/` 를 입력합니다. 그다음 온라인 화면의 엔진 연결에 `http://127.0.0.1:47831` 과 실행 창의 연결 키를 넣습니다. 브라우저가 로컬 네트워크 접근을 물으면 허용하세요. 연결 키는 공개 저장소에 올리지 않습니다.

`온라인연결.bat`는 입력한 github.io 출처만 그 실행 동안 허용합니다. 같은 github.io 계정의 다른 저장소도 같은 출처를 공유하므로, 신뢰할 수 있는 계정에서만 게시하세요.
